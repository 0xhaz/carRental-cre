## Vehicle Registry System

## Contract

- [VehicleNFT.sol](./VehicleNFT.sol) - ERC-721 implementation with:
  - VIN-based vehicle registration
  - Metadata storage (make, model, year, mileage, etc.)
  - Status tracking (Available, Rented, Maintenance, Retired)
  - Links to AssetToken and RevenueToken
  - Maintenance and incident history tracking
  - Operator-based access control
